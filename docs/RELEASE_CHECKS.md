## 安全改动与边界

- 移除可预测的会话与媒体签名默认密钥，开发环境使用进程随机密钥。
- 生产启动直接验证管理员配置、强会话密钥与 HTTPS 公网地址；缺少配置时拒绝启动。
- 本地初始化生成随机配置文件，权限为 0600，不覆盖现有文件。
- 付费模型生成、生产部署和真实业务负载未验证；本次测试未产生供应商调用费用。
- 保持单实例部署。JSON 文件存储仍是现有架构限制，不支持直接多实例共享写入。
- 扫描与自动测试只能提供有限证据，不能保证没有所有漏洞。上线前应配置自己的凭证、域名、备份、访问控制及运营文案。
