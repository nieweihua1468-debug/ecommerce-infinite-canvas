# Commerce Canvas · 电商无限画布

面向电商内容创作的可视化工作流应用：在无限画布上组织商品素材、提示词、文案、图片、音频和视频，并连接可配置的 AI 服务。

本仓库是清理私人配置和素材后的完整应用公开版，保留 React 前端、Node.js 后端、管理后台、账号权限和模型适配器。模型调用需要使用者自行配置有效凭证；仓库不提供共享密钥、商业素材或已部署的在线服务。

## 功能

- 无限画布：节点编排、连线、自动布局、素材引用、结果节点和模板导入。
- 电商创作：图文工作流、视频制作、口播素材、商品详情页结构、九宫格切图。
- 素材与任务：用户素材库、生成记录、工作队列、失败恢复及下载。
- 账号与管理：登录、账户隔离、团队与模板权限、积分和模型配置。
- 服务适配：Kling、火山引擎、DeepSeek、MiniMax 和兼容接口；支持 MCP 接入。

公开版仅附带无品牌的 SVG 占位图和通用模板结构。原有品牌产品库、图片/视频、二维码、备案信息、生产环境地址及业务数据均不随源码分发。请上传你有权使用的真实素材。

## 本地运行

需要 Node.js 20.19+ 或 22/24，npm 10+。

```bash
npm ci
npm run setup
npm run dev
```

创作端：<http://127.0.0.1:5173>；管理端：<http://127.0.0.1:5173/admin>。

`setup` 只在 `.env.local` 不存在时创建它，以 0600 权限生成独立的随机管理员密码、会话密钥和回调密钥，不会覆盖现有配置。管理员账号默认是 `admin`，密码在本机 `.env.local` 中。开发模式的自动管理会话仅供回环地址访问，生产模式关闭该入口。

编辑 `.env.local`，填写你使用的模型服务凭证与模型 ID。未配置的服务不可生成，画布与后台仍可在本地使用。媒体处理使用随依赖安装的 FFmpeg/FFprobe，或设置 `FFMPEG_PATH`、`FFPROBE_PATH` 指向本机程序。

## 检查与构建

```bash

```

本地构建后可运行 `npm run smoke:launch:local` 检查已启动的后端。真实模型调用会产生供应商费用，不属于离线测试。

## 自行部署

```bash
npm ci
npm run build
npm run preflight
npm start
```

部署前需配置独立强密码、至少 32 字符的随机 `ADMIN_SESSION_SECRET`、自己的 HTTPS `PUBLIC_BASE_URL`、匹配的 `MCP_ALLOWED_ORIGINS` 和所需模型凭证。生产预检会在配置缺失时拒绝启动；直接启动后端也会验证核心生产配置。

后端默认监听 `127.0.0.1:8791`，应在 HTTPS 反向代理后使用。`deploy/nginx-main-site.conf` 与 `deploy/commerce-canvas.service` 是需按实际环境调整的示例。保持单实例运行，数据在 `data/` 中，需独立备份并限制文件权限。JSON 文件存储不适用于多实例并发部署。

生产运营者应自行填写适用的服务条款、隐私政策和依法需要的备案信息；源码里的说明文案不是运营资质或法律保证。

## 隐私与安全

- `.env.local`、业务数据库、生成文件、日志和本机临时产物均被 Git 忽略。
- 公开仓库使用新的提交历史，未继承私人项目的旧提交。
- 缺少有效密钥时，开发会话使用每次进程启动生成的随机密钥；生产环境拒绝启动。
- 外部素材下载、用户权限、生成文件签名等已有针对性测试。
- 未配置任何追踪服务。用户主动调用模型时，必要的素材和提示词会发送到所选服务商。

发布前的扫描和测试结果见 [发布检查记录](docs/RELEASE_CHECKS.md)。扫描不能保证不存在所有漏洞；请勿将真实凭证或业务数据提交到 Issues。
